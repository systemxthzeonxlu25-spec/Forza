## 官方字段交叉核对

来源于 [FM Data Out 文档](https://support.forza.net/hc/en-us/articles/21742934024211-Forza-Motorsport-Data-Out-Documentation) 与 [FH6 Data Out 文档](https://support.forza.net/hc/en-us/articles/51744149102611-Forza-Horizon-6-Data-Out-Documentation)，访问日期 2026-10-23。下表是按声明的字段顺序、位宽和项目现有紧密小端布局推算的偏移，不是文档直接给出的偏移表。

| 字段 | FM 字节偏移 | Horizon 字节偏移 | 核对结果 |
|---|---:|---:|---|
| TimestampMS | 4 | 4 | U32，保留溢出前高位值 |
| 四轮纵向滑移 | 84、88、92、96 | 相同 | F32；原值保留，FL/FR/RL/RR 顺序正确 |
| 四轮侧偏 / 综合滑移 | 164–176 / 180–192 | 相同 | 归一化量，不是角度或百分比；绝对值超过 1 的语义与文档一致 |
| 积水 | 132–144 | 相同 | FM 为 F32 深度；FH6 为 S32 标志，不能共用类型 |
| 位置 X/Y/Z | 232/236/240 | 244/248/252 | Horizon 比 FM 多 12 字节 |
| 车速 | 244 | 256 | F32；m/s 转 km/h 为 ×3.6，独立样本 25 → 90 |
| 四轮胎温 | 256–268 | 268–280 | F32；**官方未说明单位** |
| 最佳 / 上圈 / 当前圈 / 比赛时间 | 284/288/292/296 | 296/300/304/308 | F32；FH6 文档明确秒，采样验证字段没有错位 |
| 已完成圈数 | 300 | 312 | U16 |
| 油门 / 刹车 / 离合 / 手刹 | 303–306 | 315–318 | U8 0–255，分析通道除以 255 |
| 方向输入 | 308 | 320 | S8；正常范围 −127 至 127 |
| 磨损 / 赛道 ID | 311–323 / 327 | 无 | 只对已知 331 字节 FM2023 布局读取 |

FH6 的 CarGroup 是 U32；另外两个碰撞 F32 字段继续以 U32 原始位模式保留，并未拿来作物理诊断。FH4/5 没有本次取得的官方专属逐字段结构；复用 Horizon 偏移和既有小端解释只能记为待实机验证。官方文档不能消除同为 324 字节时的代数歧义。

胎温 F→C 的数学换算和 C 模式透传均通过测试，但无法证明游戏发来的值就是 F。滑移正负号在抓包中的实际方向、诊断阈值和不同轮胎的温度区间也没有通过游戏校准。

## 已修复的确定问题

1. **FH6 字段类型**：显式 `--game fh6` 时按整数读取积水和无符号 CarGroup；不把这项变化强套到 FH5。样本中整数 1 以前会变成约 `1.4e-45`。
2. **未知包长过早用于分析**：探测未达门槛前只输出公共 Sled 信息，避免静止时猜错 Dash 偏移并落盘。仅车速吻合不再被用来证明 FM2023 尾部字段；额外零字节不会凭空变成赛道 0 和零磨损。
3. **异常核心浮点值**：车速、位置、距离和计时中的 NaN/Infinity 不再进入切圈链路。可选显示字段的空值处理保留原有行为。
4. **接近终点时重开**：不再以 95% 距离把中断圈算成完整圈。Horizon 无过线记录仍保留，标为不完整和中断。
5. **倒带最高车速**：随被删采样一起撤销，重新计算保留样本的峰值。
6. **缺少 CurrentLap 的首秒**：不再等满一秒才开始持续采样，避免首秒只剩一行。
7. **中途接入**：不完整的首圈不能更新参考圈长、成为当前/历史最快或充当挂起圈参考。它仍可保存供检查。
8. **深倒带**：跨回已落盘圈时使旧成绩失效；跨越多圈时丢掉被抹除的挂起圈。失效更新与 INSERT 使用同一后台队列；PB 缓存和旧小结随之撤销。旧轨迹保留供审查，不自动恢复为新的完整圈。
9. 增加本机绑定参数，便于只录 UDP 或仅本机查看；列表新增中途接入、完赛推定、中断、倒带失效提示。

回归测试先在原代码上复现失败，再验证修复。已有断言只在行为有意收紧时调整：未知扩展包不能自称 FM2023；暂停后直接时钟重置的冲刺记录不能仅靠猜测晋升完整圈。

## 仍需真实游戏验证的部分

- **完赛不是可靠信号**：首趟冲刺的“完整”、末圈 95% 距离、30 秒静默结束事件仍是启发式。首次跑半程后退出、长暂停、赛后停止发包可能误判。新增 `finish_inferred` 只揭示推断性质，未把它升级成已证实完赛。
- **重开和近起点倒带**：比赛时间回到 1.5 秒内仍可能被认为重开；需同一台 FH5 的两种样本确定可用区分信号。
- **UDP 乱序/丢包**：本次有实际网络收发，但用了接收计数同步，没有模拟公网或无线拥塞。当前状态机主要依赖比赛时间；不能据本次通过宣称任意乱序可恢复。
- **路线和游戏识别**：FH5 缺少可信赛道 ID，位置/长度指纹可能合并同起点路线；324 字节无法识别代数。用户指定游戏仍是必要输入。
- **温度与诊断**：F/C、轮滑符号、车辆动力学阈值、辅助系统介入后的信号需对照游戏遥测，不能仅凭合成曲线批准调校建议。
- **真实客户端**：Windows 接收、商店版回环限制、游戏 HUD、实际手机浏览器、60/120/高帧率下的丢包行为均未实测。

因此当前适合进入 FH5 实机采样阶段，不应标注“已通过真实 Forza 数据验收”。

## 最短 FH5 实机采样流程

使用本次修复分支，在游戏和工具同一台电脑上操作。先按 README 安装依赖，在项目根目录运行：

```powershell
python -m forza record --game fh5 --udp-host 127.0.0.1 --udp-port 5555 --duration 600 -o recordings/fh5-acceptance.frec
```

FH5 设置 → HUD 和游戏玩法 → Data Out 开启；目标 IP 填 `127.0.0.1`，端口 `5555`。本机 Data Out 设置可参考设备厂商的 [FH5 PC 接入文档](https://www.simrig.se/documentation/control-center/game-setup/forza-horizon5.html)；端口使用本项目的 5555，两端一致即可。这个命令只收 UDP，不开网页。开始驾驶后应看到包数增长，结束可 Ctrl+C；不要复用已有文件名，以免覆盖旧录像。

若一直为 0 包，先确认在驾驶而非菜单；商店版按 README 的回环排查处理。需要用局域网 IP 时，把命令的 `--udp-host` 和游戏目标 IP 都改成该电脑的具体局域网地址，仍不开 HTTP 或公网端口。

建议每种场景独立录一个 `.frec`，不必做复杂准备：

| 样本 | 最少操作 | 需要同时记下/截取的游戏证据 |
|---|---|---|
| 基础 + 圈速 | 短赛道完整跑 3 圈；直道稳住一次速度；分别踩满油门、刹车、离合/手刹 | 游戏速度单位、遥测踏板百分比、每圈官方成绩、车辆和赛事名 |
| 温度 | 打开轮胎遥测，冷胎及跑热后各截图一次；记录当前显示单位 | 四个轮胎的数值和单位。游戏若显示胎面内/中/外三点，保留整页，不能假定 UDP 的单值等于某一点 |
| 倒带 / 重开 | 圈内倒带；过线后倒带；若游戏允许，再跨回过线超过 12 秒的圈；另录接近终点时重开 | 同步短视频或操作时间，避免把“重开”标签当成猜测 |
| 冲刺 | 同一路线跑完一次，再半途退出一次；另在首次采集的新路线只跑半程退出 | 明确出现的完成/退出画面、最终用时及路线名 |

最小交付是一段基础 `.frec` 加游戏成绩/遥测画面；后两类用于补状态机验收。记录 FH5 版本、Steam/商店版、辅助选项、显示单位和录像内的大致操作时间。原始包无法替代这些观察，观察也不要由分析器自己的输出代填。

录完可离线检查，使用单独的验收库：

```powershell
python -m forza info recordings/fh5-acceptance.frec --game fh5
python -m forza import recordings/fh5-acceptance.frec --game fh5 --tire-unit F --db data/fh5-acceptance.db
```

这里的 `--tire-unit F` 是待验证的现有默认假设。若要比较 C 解释，改用另一个数据库和 `--tire-unit C` 重新导入，不能直接把两份当作已校准数据。`.frec` 保留原始字节，可重复解析；后续 info/import/replay 请继续明确传游戏和单位，不假定旧录像头能自动配置解析器。

确需本机看图时，可运行下面命令，只监听回环地址：

```powershell
python -m forza serve --replay recordings/fh5-acceptance.frec --game fh5 --tire-unit F --http-host 127.0.0.1 --db data/fh5-preview.db
```

浏览器打开 `http://127.0.0.1:8000`。预览与验收用不同数据库，避免回放再次存档导致重复圈。手机检查属于后续单独的局域网验证，本次未执行。
