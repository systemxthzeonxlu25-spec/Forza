# Forza 遥测分析工具

给 **Forza Motorsport（FM7 / FM 2023）** 和 **Forza Horizon（FH4 / FH5 / FH6）** 用的练车、调车小工具：

- **实时面板**：手机浏览器当副屏，显示车速、转速、档位、油门/刹车/方向、四轮胎温、悬挂行程、滑移率、G 值
- **自动切圈 + 存档**：用游戏给的圈数/圈时字段自动切圈，每圈存进本地 SQLite
- **两圈对比**：按赛道距离叠加速度、油门、刹车曲线，自动切出弯道，告诉你在哪个弯慢了、慢在哪
- **调车诊断**：根据一圈数据给出转向不足/过度、悬挂触底、胎温不均、出弯打滑、刹车抱死、齿比等提示，每条都写明判断依据
- **录制 / 回放**：把原始 UDP 包录成文件，不开游戏也能开发调试；还能生成假数据
