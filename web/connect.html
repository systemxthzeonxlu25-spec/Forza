游戏里怎么填（Data Out）

在游戏设置里找到 Data Out（HUD / 游戏玩法 那一页的最下面），Data Out = 开（On），再按下表填 IP 和端口：

游戏和本程序在同一台电脑：先填 127.0.0.1，收不到再改填局域网 IP。在 Xbox 或另一台电脑上玩：填运行本程序这台电脑的局域网 IP。Microsoft Store / Game Pass 版收不到数据，见 README 里的“回环豁免”。

手机打不开页面？

  • 第一次运行时 Windows 防火墙会弹窗：勾选专用网络，允许 Python 访问。
  • 错过了弹窗：Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙 → 给 Python 勾上“专用”；或者用管理员 PowerShell 放行 TCP 8000 端口：
    New-NetFirewallRule -DisplayName "Forza Telemetry Web" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
  • 电脑当前的网络要设成专用网络（设置 → 网络和 Internet → 网络配置文件类型）。
  • 手机别连访客 Wi-Fi；路由器开了“AP 隔离 / 客户端隔离”也会挡住。
